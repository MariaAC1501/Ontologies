# OPMAD conversion

Generated by `scripts/convert_opmad.py`. This README replaces the JSON manifest
and is refreshed on each conversion. Run from the repository root:

```sh
uv run scripts/convert_opmad.py
```

Use `--source-dir` or `--output-dir` to override the default paths.

## OntoCast input and usage

`ontocast/OPMAD.ttl` includes OPMAD and the bundled dependencies, with their definitions, axioms and annotations.
Only the 8 dependency subjects' `rdf:type owl:Ontology`
declarations are removed, so OPMAD remains the sole declared ontology for OntoCast compatibility.

The dependency ontology declarations are an explicitly approved RDF
loss in the OntoCast view. They remain in the original source files.

### With dependencies

Point `--ontology-dir` at the `ontocast` subdirectory, not this parent folder.
With your LLM configuration set, use facts-only mode to keep the schema fixed:

```sh
RENDER_MODE=facts \
ONTOLOGY_CONTEXT_MODE=fixed_single_ontology \
ONTOLOGY_CONTEXT_FIXED_ONTOLOGY_ID='http://www.semanticweb.org/j.montero-jimenez/ontologies/2021/2/OPMAD' \
ONTOLOGY_CONTEXT_REQUIRED=true \
ontocast process --ontology-dir ontologies/opmad/ontocast \
  --input-path papers/pdfs --output-dir out/opmad
```
